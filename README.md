# フルリエル公式サイト v9 — キャスト管理対応版

v8の見た目を維持しつつ、Pages CMS（GitHub）でメイド図鑑を編集できるようにしました。
**現時点ではGitHub / Cloudflare Pagesへの接続は未実施です。** ZIPをダウンロードしただけではオンライン管理画面は開設されません。

## まず試す

ZIPを解凍し `index.html` をブラウザで開いてください。収録済み名簿はメイド21枠・黒服12枠です。
Windowsの場合 Node.js をインストールすると `node scripts/build.mjs` で名簿を再生成できます。

## 実際の運営で使う（無料枠）

1. GitHub にリポジトリを作り、このフォルダ**内のファイルをルートに**アップロードします（`dist` は生成物でGit管理不要）。
2. [Pages CMS](https://app.pagescms.org/) にGitHubでログイン、作ったリポジトリへのアクセスを承認します。`.pages.yml` を読み込むと「キャスト名簿」を編集できます。
3. [Cloudflare Pages](https://dash.cloudflare.com/) で **GitHubからデプロイ** を選び、同リポジトリを接続。
4. Cloudflare Pagesの設定： **Build command** `node scripts/build.mjs` / **Build output directory** `dist` / **Root directory** 空欄（リポジトリ直下）。Framework preset は None。
5. Node.jsのバージョンは18以降にします。`NODE_VERSION=22` を環境変数で指定しても構いません。
6. GitHubのmainブランチが更新されるとCloudflare Pagesが自動再ビルドして公開サイトに反映します（通常多少の時間差あり）。

**重要:** もともとZIPを手動でアップロードする方式のCloudflare Pagesサイトに後からGit連携を追加できない場合があります。新規にGit連携方式のプロジェクトを作成するのが確実です。

## 新しいキャストの登録

Pages CMSの「キャスト名簿」→「New」→ 名前・読み仮名を入力 → 「メイドとして掲載」「黒服として掲載」を選択 → 立ち絵と音声を各欄でアップロード/選択 → 自己紹介を書く → 最後に「公開する」をオン → 保存。画像も音声も**そのキャストのレコードの項目で関連付ける**ため、ファイル名一致は不要です。

兼任（メイドと黒服に登場）は1件の登録で両方をオンにしてください。両方に同じ自己紹介・画像・ボイスが表示されます。

## 卒業・一時お休み

Pages CMSのキャスト編集画面で「公式サイトに公開する」をオフ → 保存。再度オンにすると復活します。
完全削除する場合はPages CMSのレコード削除機能を使ってください。**削除は元に戻しづらいため、基本は非公開がおすすめです。** 画像や音声ファイルは別管理のため、必要ならメディア管理から個別に消してください。

## 素材について

- 写真・立ち絵は WebP または JPG/PNG を推奨（目安 1MB以下）
- ボイスは MP3 / 15〜30秒程度を推奨（目安 1MB程度）
- Cloudflare Pages/GitHubの容量・ファイルサイズ上限を超える素材は別途圧縮が必要です
- 必ず本人にサイト公開・保存・二次利用・公開停止依頼の可否を確認してください
- 名前・本文に秘密情報は記載しないでください。公開リポジトリの履歴に残る場合があります

## 仕組み

- `.pages.yml` : Pages CMSの編集画面項目定義
- `content/casts/*.json` : 1名につき1ファイルのデータ（兼任していても1件）
- `assets/casts/` : キャスト画像
- `assets/voices/` : ボイス
- `scripts/build.mjs` : JSONから `casts.js` を生成し `dist/` にサイトを出力
- `casts.js` : ブラウザ表示用の生成データ（手動編集しない）
- `app.js` : 既存の検索・詳細・お気に入り・音声再生機能
- `dist/` : Cloudflare Pages に公開するファイル
